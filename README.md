# Présentation interactive — technologies du diabète

**Catégorie : santé, vulgarisation & présentation technique** · Studio Niko Design

Ce dépôt contient une présentation web indépendante sur les technologies liées au diabète et aux systèmes en boucle fermée. Le fichier `index.html` se présente comme « NIKO AI | Global Engineering Pack » et charge notamment Chart.js, JSZip et FileSaver.js.

## Consulter la présentation

Ouvrir `index.html` dans un navigateur récent. Pour tester le projet avec un serveur local :

```bash
python3 -m http.server 8000
```

Accéder ensuite à http://localhost:8000/.

## Structure

- `index.html` — présentation interactive principale.
- `presentation medtronic.html` — autre fichier de présentation HTML.
- `README.md` — description et précautions.

## Dépendances
